## PalindromeCheckerApp

## 📌 Objective
The objective of this project is to create a Java application that checks whether a given string is a palindrome or not.
This project also demonstrates proper Git workflow using branches, commits, push, pull requests, and merge.

---

## 🛠 Tools & Technologies Used
- Java
- IntelliJ IDEA
- Git
- GitHub

---

## 🔄 Running Procedure

1. Open Documents folder.
2. Create a folder with your Full Roll Number.
3. Create a GitHub repository named **PalindroneCheckerApp**.
4. Clone the repository:
   git clone <repository_link>
5. Open the project in IntelliJ IDEA.
6. Create a module named **App**.
7. Inside src folder create:
   PalindromeCheckerApp.java
8. Run the program from IntelliJ terminal or Run button.

---

## 📊 Project Flow

1. Repository creation in GitHub.
2. Cloned repository to local system.
3. Opened project in IntelliJ.
4. Created new branch for Use Case.
5. Implemented palindrome logic.
6. Added specific files using git add command.
7. Committed changes.
8. Pushed branch to GitHub.
9. Created Pull Request.
10. Merged branch into main.
11. Pulled latest code from main before starting new use case.
